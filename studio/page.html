Réglages

Relie l'appli à Jellyfin : tes bibliothèques apparaissent comme dossiers, et Jellyfin s'actualise tout seul après chaque vidéo.

Pour la clé : Jellyfin → Tableau de bord → Clés API → « + », nom « Frigo Rosé Studio ».
Après chaque téléchargement, Studio demande à Tunarr de relire la médiathèque : la vidéo est direct dans « Add Media ».

Ça marche partout où ton téléphone a internet, tant que le PC est allumé avec Studio ouvert.
